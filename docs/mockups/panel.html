Command box — three states, never two

The live box in the panel is showing the valid state: the Monte Carlo/exact preview is the validator, so a healthy string spends its message slot on information instead of reassurance. Below, the other two states, frozen. The slot is a fixed 18 px and the caret line is always reserved, so switching states never moves the panel.

Incomplete — every prefix of a valid command. Border unchanged, never red.
Invalid — caret under error.index, plain-language message, one-click fix.

§1.2 · §1.3

Chips can't lie

Group rows render canonical notation including mods from the stored spec through the same renderer the box and the #g= codec use — the row cannot advertise 1d20 and roll advantage. Click a chip to copy it; the copied text is pasteable because chip text is canonical form.

§1.4

One string, two editors

Spec object is truth; notation is its projection. Die buttons and tray chips rewrite the box; popover controls rewrite it too — every control in the ± popover above re-renders the echo line, the preview and the Roll button's badge.

§1.5

Gold is rationed

§5.1 allows ornament on one element for a few seconds — the roll-moment card, not the panel. So the panel stays flat: hairline dividers, 10 px letterspaced small-caps section labels, one filled gold button per panel (the tray's Roll, and the popover's Roll while it is on stage). The seven per-row Roll buttons are outlined; selected states use a 16% gold wash rather than a fill. Notation is monospace with tabular-nums everywhere so numbers never reflow.

Panel width goes 268 px → 296 px: the row now carries a notation chip, badges, ±, Roll and delete. That is the one measurement this mockup changes.

§5.1 · §5.2

Non-open modes are always visible

A sticky secret default is the top accident vector, so any non-open mode paints an eye-slash on the Roll button, the group row, and the mini pill. The command box is hidden in mini mode; pills carry the canonical notation in their title and fall back to it when a group has no name.

§3.2 · §1.4 · §2.6

Mat text belongs to the table

The Mat text field writes the declaration into the felt under the dice — a canvas decal on the table plane, not a DOM heading. Edit the field in the popover and watch the felt at the bottom of this page change; set the Moment to Plain and the words leave. That is the whole reason a Check feels like an event: the room is dressed, not the sidebar.
